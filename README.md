# 軍團倍增攻城戰 ✕ 王國要塞防禦 3D (Crowd Siege & Tower Defense)

> 🎮 **一款融合「算術倍增跑酷衝鋒」與「立體多層建築防禦塔攻防」的 3D 複合策略遊戲！**

---

## 🌟 遊戲核心特色

- **🏰 攻防合一創新玩法**：
  打破傳統跑酷與塔防界限，玩家在前線帶領部隊穿過算術能量門擴充軍力，並在終點向敵方防守要塞發動總攻；亦可切換至防守模式抵禦波次敵軍。
- **🏛️ 3D 建築結構防禦塔**：
  防禦塔具備精細的建築多層結構，配備可動部件與動態特效：
  - **🏹 皇家連弩塔**：八角石砌階梯基座、斜面石砌塔身、觀測箭窗、垛口城垛、尖頂巫師瓦片屋頂，塔頂 3D 弩弓手自動旋轉瞄準。
  - **💣 重裝加農砲塔**：八角鋼鐵鉚釘底座、裝甲圓柱塔身、360° 旋轉機械砲座、雙聯消焰加農砲管，帶開火後座力回縮動畫。
  - **❄️ 永凍冰晶魔塔**：符文雕刻石基座、四角螺旋結晶柱、懸浮自轉的透光八面體冰晶核心與公轉微型碎晶，釋放範圍極寒冰風暴。
  - **⚡ 特斯拉超能塔**：高壓絕緣瓷瓶基座、層疊銅質電磁線圈、金屬放電球與跳動電漿電弧，發射連鎖閃電鏈。
  - **🏰 終點防衛巨型城寨**：雙聯角樓衛塔、拱頂城門、重型鐵閘門、迎風飄揚旗幟與 3D 即時浮動血條。
- **🦾 泰坦神兵合體機制 (Titan Fusion)**：
  部隊數量充足時，可按下 `1` 或 `空白鍵` 將 20 名步兵融合成手持巨大戰鎚的「鋼鐵泰坦霸王兵」，具備範圍震波與攻城破甲能力。
- **🌀 極性反轉力場 (Gate Inversion)**：
  按下 `2` 鍵將前方除法或減法門強行反轉為 X3 增幅光門，靈活扭轉前線戰局。
- **☄️ 天降神罰流星雨 (Meteor Strike)**：
  按下 `3` 鍵召喚天外隕石，直接消滅前方大片敵軍阻礙。
- **🎥 自由鏡頭切換**：
  按下 `V` 鍵即時在「跟隨跑酷視角」、「等軸戰術塔防視角 (Isometric)」與「高空上帝指揮視角」自由切換。

---

## 🎮 四大遊戲模式

1. **🏰 軍團倍增攻城戰**：
   在賽道上左右行進，精確計算乘法與加法門擴大軍團人數，躲避致命旋轉電鋸陷阱，擊潰中途敵軍伏擊，最終合力攻破敵方多層防衛要塞！
2. **🛡️ 王國策略塔防**：
   在道路兩側的專屬插槽自由佈署連弩塔、加農砲塔、冰晶塔與特斯拉塔，抵禦洶湧而來的多波敵軍部隊！
3. **⚔️ 雙向陣營對推**：
   紅藍兩軍在中央戰場交鋒，爭奪中場移動式算術門，比拼兵線推進與破塔速度！
4. **♾️ 無盡狂潮生存**：
   挑戰無限波次與極限數值增長，考驗操作反應與策略極限。

## 🕹️ 遊戲操作指南

| 控制方式 | 按鍵 / 動作 | 功能說明 |
| :--- | :--- | :--- |
| **軍團移動** | `A` / `D` 或 `←` / `→` | 左右操控軍團行進方向 |
| **滑鼠牽引** | 按住滑鼠左鍵左右拖曳 | 流暢牽引軍團隊伍穿過最佳數值門 |
| **泰坦合體** | `空白鍵` 或 數字鍵 `1` | 消耗 20 名步兵召喚重裝鋼鐵泰坦 |
| **極性反轉** | 數字鍵 `2` | 將前方負面除法/減法門轉化為 X3 增幅光門 |
| **天降流星** | 數字鍵 `3` | 召喚流星轟炸前方敵軍隊列與防禦外塔 |
| **視角切換** | `V` 鍵 或 頂部 🎥 按鈕 | 在「跑酷跟隨」⇄「等軸戰術」⇄「高空俯瞰」視角切換 |
| **建造防禦塔** | 點選底部卡片後點擊地圖插槽 | 在王國塔防模式下建造與配置防禦塔陣 |

## 🚀 啟動與執行方式

本遊戲完全支援離線直接開啟與本機伺服器運行：

### 方式一：直接雙擊點開（推薦，100% 離線免安裝）
- 直接點擊開啟專案中的 [`index.html`](file:///c:/Users/dysh/Desktop/114310/index.html) 或單檔整合版 [`game_standalone.html`](file:///c:/Users/dysh/Desktop/114310/game_standalone.html)。
- 支援 Chrome、Edge、Firefox 等主流瀏覽器，無須任何外部網路連線即可流暢執行。

### 方式二：使用本機伺服器
```bash
node server.js
```
伺服器運行於 `http://localhost:3000/`。
